# Project 3 support files

This package separates the scientific implementation, configuration, saved data, and figures from the main report notebook.

The central design principle is:

- **Configuration** changes experiment inputs.
- **`src/`** contains reusable scientific code.
- **`scripts/`** regenerate experiments.
- **`data/results/`** stores compact raw/summary results.
- **`data/solutions/`** stores per-run wavefunctions when experiments are rerun.
- **`figures/`** stores report graphics.

See `README_UPLOAD_GUIDE.md` for upload instructions.
